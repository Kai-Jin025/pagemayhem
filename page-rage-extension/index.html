Page Rage Extension: How to Install and Use It on Any Page

The Page Rage extension puts a "break this page" button in your browser toolbar. One click turns the tab you are on into a destructible level — here is how to install it in Chrome, Firefox or Edge, how to use it, and what to do when it will not cooperate.

What the extension does

Page Rage is a free browser game with a jetpack, around ten weapons and a set of built-in pages to wreck. The extension is its convenience layer. Normally, adopting a page into the game means copying the URL, opening the game, pasting and waiting — four steps between you and catharsis. The extension deletes all four. Install it, and a small icon sits in your toolbar; whenever a website earns your rage — an unskippable popup, a checkout that forgot your cart, a "we value your privacy" wall that values nothing — you click once and the game opens with that exact page rebuilt as a level.

It is the official extension from the game's own developers (you will sometimes see it described as the "Break This Page" button), it is free like the game itself, and there is no account involved.

How to install it (Chrome, Firefox and Edge)

Installation is a two-minute job in any browser, and it always follows the same four beats: find the listing → add → approve the permission prompt → pin the icon. Install from your browser's official store — that is the copy the game's developers publish, and the one that updates itself.

Chrome

  1. Open the Chrome Web Store and search for Page Rage.
  2. On the listing, click Add to Chrome and confirm the permission prompt.
  3. Click the puzzle-piece icon in the toolbar, find Page Rage, and click the pin so the button stays visible.

Firefox

  1. Open Firefox Add-ons (addons.mozilla.org) and search for Page Rage.
  2. Click Add to Firefox and confirm.
  3. The icon appears in the toolbar — if it doesn't, it is waiting in the extensions (puzzle) menu; right-click it and choose to pin it.

Edge

  1. Open Edge Add-ons and search for Page Rage.
  2. Click Get and confirm the prompt.
  3. Pin the icon from the extensions menu so the button is one click away.

If a store search comes up empty, start at page-rage.com instead — the official site links to the current listing for each supported browser, which is also the safest way to make sure you are installing the real extension and not a lookalike.

How to use it on any page

  1. Open any normal website in the browser where you installed the extension. It can be anything that is not behind a login — a news homepage, a wiki, that game you rage-quit.
  2. Click the Page Rage icon in the toolbar. The game opens with the page you were just looking at rebuilt as a destructible level. No URL copying, no tab juggling.
  3. Play as usual. Fly with the jetpack, aim with the mouse, dash with space, and swap between the game's weapons with the number keys — the in-game tutorial on first load shows the exact bindings.
  4. Done? Close the tab. The real website was never touched — the game worked on its own rebuilt copy the whole time.

Heavy media pages load chunkier than simple text pages; if the level feels laggy, try a blog or a wiki — the main Page Rage guide has more on which pages make the best levels.

What it asks permission for — and what it does not do

Like any extension that works on pages you choose, Page Rage asks for permission to read the page you are on. That sounds broad, but it is exactly its job: when you click the button, it needs to read the page in front of you in order to rebuild it as a level. Without that permission, the whole feature cannot exist.

What it does not do is worth stating plainly, because this genre confuses people: it does not modify the real website. The destruction happens on a local copy inside the game — the site you "destroy" is never changed, never slow, never even aware. Nothing you smash is visible to the site's owners or to anyone else, and the extension does not post, comment or send messages on your behalf.

The usual extension hygiene applies: install from the official store listing, keep your browser updated, and remove anything you stop using (the steps are below).

If the extension isn't working

  • Nothing happens when you click. Reload the tab first, then click again — an extension often can't act on a page that was already open when it was installed.
  • Check that it is actually enabled. Browsers sometimes install new extensions in a disabled state until you confirm. Open your browser's extensions page (chrome://extensions, about:addons or edge://extensions) and make sure Page Rage is switched on.
  • Some pages simply can't be captured. Browser system pages — the new-tab page, settings, the add-on store itself — are off-limits, pages behind a login can't be reached, and a few sites refuse to be embedded. These are the same limits you hit when pasting a URL into the game directly.
  • The level is choppy or half-broken. Media-heavy pages are the usual culprits. Try a simpler, text-heavy page instead — they run smoothest.
  • The icon has vanished. It is probably just unpinned. Click the puzzle-piece icon next to your address bar and pin Page Rage back to the toolbar.
  • The game itself won't open at all. Test page-rage.com's built-in pages in a normal tab first. If those don't run either, update your browser and the extension, then try again.

How to remove it

Changed your mind, or just tidying up? Removing an extension takes ten seconds in any browser:

  • Chrome: open chrome://extensions, find Page Rage, click Remove.
  • Firefox: open about:addons, find Page Rage, click Remove.
  • Edge: open edge://extensions, find Page Rage, click Remove.

Removing the extension does not affect the game itself — page-rage.com still works in a normal tab, and you can always reinstall later.
